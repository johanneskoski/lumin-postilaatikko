# Lumin postilaatikko

Pieni sivu, jolla kirjoitetaan Lumille ja luetaan hänen vastauksensa. Lumi on paikallinen kielimalli (Gemma 4 12B), joka toimii Johanneksen omalla koneella. Kirjeet kulkevat yksityisen repon kautta, ja koneella pyörivä postinkantaja vie ne Lumille.

- Tässä repossa ei ole kirjeitä, muistiinpanoja eikä tunnuksia. Täällä on vain sivun koodi.
- Sivu tarvitsee GitHub-tunnuksen, jolla on luku- ja kirjoitusoikeus vain Lumin repoon. Tunnus tallentuu vain käyttäjän omaan selaimeen.
- Sivu on yksi HTML-tiedosto ilman ulkopuolisia skriptejä. Sen sisältöturvakäytäntö sallii yhteydet vain GitHubin rajapintaan, ja sen oma skripti on lukittu tiivisteellä.
