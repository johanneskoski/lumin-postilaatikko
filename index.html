Lumin postilaatikko

Täällä voit kirjoittaa Lumille ja lukea hänen vastauksensa. Kirjeet kulkevat Lumin yksityisen pesän kautta, ja Johanneksen pelikoneen postinkantaja vie ne Lumille.

Postilaatikko tarvitsee GitHub-tunnuksen, joka tallentuu vain tähän selaimeen:

  1. Avaa github.com/settings/personal-access-tokens/new.
  2. Valitse Repository access → Only select repositories → lumi.
  3. Valitse Permissions → Contents → Read and write ja luo tunnus.
  4. Liitä tunnus asetuksiin.
